# Portfolio Projects

In my pursuit of telling stories of various worldly occurrences, I have analysed different datasets. The projects in this repository contain the code behind my various publications on [martinwambugu.com](https://www.martinwambugu.com).

## Projects

### COVID Analysis
Exploration of COVID-19 case and mortality data to identify trends across countries and time periods.

### Food Price Inflation Data Exploration
Analysis of global food price inflation trends using Python (pandas, matplotlib, seaborn). Includes data preprocessing and country-level visualisations.

### Formula One Data
SQL-based analysis of Formula 1 race results, driver standings, and circuit performance including Mexico and Austin circuit lap time analysis.

### Nashville Housing
Data cleaning and transformation of Nashville housing market data using SQL.

### ML Credit Card Data Cleaning
Machine learning data preparation pipeline for credit card transaction data using Python and scikit-learn.

## Tools Used
- Python (pandas, matplotlib, seaborn, scikit-learn)
- SQL
- Google Colaboratory
- Jupyter Notebooks
